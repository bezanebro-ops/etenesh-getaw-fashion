# እቴነሽ ጌታው ፋሽን ዲዛይን — የሲስተም መመሪያ

## መጫን
1. Python 3.10+ ይጫኑ።
2. በዚህ ፎልደር ውስጥ `pip install -r requirements.txt` ያስኪዱ።
3. `streamlit run app.py` ያስኪዱ።
4. በሚከፈተው አሳሽ ላይ ሲስተሙን ይጠቀሙ።

## የሚያካትተው
- ዋና ዳሽቦርድ (Dashboard)
- ገቢና ወጪ መዝገብ (Ledger)
- የደንበኛ ትዕዛዝ (Orders)
- የብድር ክትትል (Loan Tracking)
- የምርት ዋጋ ማስያ (Pricing Calculator)
- ሪፖርት (Reports)
- SQLite ዳታቤዝ

## ማስጠንቀቂያ
ይህ የመጀመሪያ የስርዓት ስሪት ነው። የኢትዮጵያ ቀን ትክክለኛ የቀን ስሌት፣ የዕቃ ክምችት (Inventory)፣ የትርፍና ኪሳራ በወር/ዓመት፣ የተሟላ የደንበኛ መዝገብ፣ backup/restore እና የተሻለ የብድር ማስሊያ በቀጣይ ደረጃ መጨመር ይገባል።
