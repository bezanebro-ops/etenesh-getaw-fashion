# እቴነሽ ጌታው ፋሽን ዲዛይን — የመጀመሪያ የንግድ ሲስተም
1. Python 3.10+ ይጫኑ።
2. `pip install -r requirements.txt`
3. `streamlit run app.py`
4. Browser ላይ የሚከፈተውን አድራሻ ይክፈቱ።

የያዘው፦ ዳሽቦርድ፣ ገቢ/ወጪ፣ 35 ታሪካዊ ግብይቶች፣ 20 የብድር ሩብ ዓመታት፣ የዋጋ ማስያ፣ ሪፖርት።

ማስታወሻ፦ የ35ቱ ግብይቶች ትክክለኛ ቀናት ስላልተሰጡ “ቀን ያልተረጋገጠ” ተብለው ተመዝግበዋል። የብድር ክፍያ ቀኖችም ከዋናው ውል ጋር መረጋገጥ አለባቸው። ይህ የመጀመሪያ ስሪት ነው፤ ቀጣዩ ስሪት የኢትዮጵያ ዓ.ም. ቀን፣ ደንበኛ፣ ትዕዛዝ፣ እቃ ቆጠራ፣ የምርት ወጪ እና ምትኬ ይጨምራል።
